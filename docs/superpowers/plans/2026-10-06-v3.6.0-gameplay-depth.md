# Denkmal TD v3.6.0 Gameplay Depth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v3.6.0 as a deeper but still immediately understandable gameplay update centered on the three build paths KONTROLLE, PRÄZISION and RISS.

**Architecture:** Keep the current static browser architecture and existing gameplay files. Extend `dist/game.js` for build state, perks, enemy roles, elite modifiers and projectile/combat synergies; extend `dist/hero-saga.js` for Marcel's two run-time ability evolutions. Tests remain Node/vm regression tests and pin each mechanic before implementation.

**Tech Stack:** Vanilla HTML/CSS/JavaScript, Node.js regression tests, GitHub Pages static deployment.

**Spec:** `docs/superpowers/specs/2026-10-06-v3.6.0-gameplay-depth-design.md`

## Global Constraints

- Map redesign and fundamental level-structure work are deferred to v3.7.0.
- Android/touch/performance redesign is deferred to v3.8.0.
- Graphics/assets/lighting/atmosphere redesign is deferred to v3.9.0.
- No permanent skill tree, meta-currency, or mandatory new menu.
- Existing static browser structure remains build-step free.
- Existing touch and desktop controls must continue to work.
- Existing camera-shake and hit-stop rules remain unchanged.
- Build-path copy must explicitly use KONTROLLE, PRÄZISION and RISS.
- No unbounded chain loops or exponential damage scaling.

## Review Focus

- Perk rolls with repeated/random choices must never offer unusable or duplicate-exclusive evolution choices.
- Elite modifiers must survive normal wave scaling without stacking multiple modifiers on one enemy.
- Slow-resistant enemies must still be slowable to a reduced degree rather than becoming immune and breaking control builds.
- Rift return-chain logic must never hit indefinitely or exceed its explicit bounce budget.
- Precision focus state must reset cleanly when the target dies or changes, so bonus damage never leaks to unrelated enemies.
