# Persistent loot — v3.6.0-alpha.1

User requirements: Diablo-inspired loot/inventory, permanently retained finds, equipment changes exclusively in the main menu. User authorized autonomous implementation through release on 2026-10-08; no intermediate approval gates. Implement in an isolated branch; review before release.

## Player experience
Main menu opens a unified inventory with portrait, eight slots (weapon, head, armor, gloves, boots, amulet, two rings), 30 backpack cells, overflow, filters/sort, and selected-item comparison. Tap or keyboard selection; explicit equip, unequip, favorite and salvage buttons. Slots are equal-sized for touch. During a run I/H opens the same inventory read-only, pausing simulation; close resumes the previous state. All equipment/import/salvage commands also enforce menu origin in the model, not just disabled controls. Item details show numerical differences and special effects. Existing story UI remains read-only.

## Progression and effects
Five rarities: common, magic, rare, epic, legendary. Bounded wave-scaled rolls; bosses guarantee epic-or-better items. Every wave grants one item so early play is rewarding. Normal enemies have a 12% equipment chance. Eight base stat types: damage, health, attack speed, movement speed, defense, crit chance, life steal, tower damage. Total bonuses have caps. Legendary affixes: lightning chain, sustain, tower support. Existing ember/echo, oath/ash and lantern/bell effects become item powers; starter equipment retains ember/oath/lantern bonuses. Alternatives unlock once at waves 3/4/8 as permanent items, usable next run. No duplicate rewards for restarting a wave. Run-only perks stay run-only.

## Ownership and saving
Inventory module owns versioned local profile: unique item instances, equipped IDs, backpack and lossless overflow, favorite flags, salvage essence and milestone flags. Equipped items do not consume backpack cells. New finds never auto-equip. At reset, game obtains a deep snapshot and derives stats once; profile changes cannot mutate it. Found items save immediately, including on defeat or return to menu. Browser reload discards the current run but keeps collection. Legacy alpha.2 has no persisted loot to migrate; preserve existing level unlock and preferences, grant its three default effects as starter items. No invented recovery of past run-only items.

Use separate primary/backup keys; validate imported and persisted data, duplicates, slots, IDs and numeric bounds. Invalid or future-version data must not be silently overwritten; try backup, show actionable status and enable export. Import is a deliberate main-menu action with validation/confirmation; reject invalid input atomically. Blocked/quota storage keeps session progress, shows warning and offers JSON export. Export includes level-2 unlock for transfer. Cross-tab profile changes lock writes until reload to prevent overwrites. Salvage rewards persistent forge essence; explicitly invest 50 essence for a reroll of a selected unequipped item's bounded stats (never destroy favorite/equipped items). Keep rarity/power intact. Overflow automatically fills freed backpack slots.
