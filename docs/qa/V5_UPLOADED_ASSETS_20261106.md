| Kim | `art/sources/v5/kim-marksman-v5b-master.png` | `dist/assets/menu/v5-avatars/kim-marksman-v5b.webp` | 480×660, ≈38.7 KiB | CSS `object-fit: contain`, top-aligned portrait overlay; no gameplay pivot |

Both PNG masters were generated by **background-extraction** image edits using the original JPEG portrait as the identity reference. Prompts locked the face, pose, clothing, sword/shield or bow/arrow and required genuine alpha with no background. The resulting artwork is **not pixel-identical to the original**; the face and small details must receive visual approval in Android Chrome before any main release.

Optimized exports: `convert <master>.png -resize 460x620 -gravity center -background none -extent 480x660 -strip -define webp:method=6 -quality 78 <runtime>.webp`.

## QA / remaining blockers

- Static QA checks real WebP decoding, RGBA, transparent corners, background fraction, no hot-pink key leakage and 150 KiB maximum per new portrait.
- Old `v5` portrait files remain unmodified for rollback; `portrait-avatars-v5.js` still waits for both images and suppresses the stage on any load failure. It does not intercept inputs or write saves.
- Portrait/mobile and landscape states use the existing non-interactive stage (`pointer-events:none`) and reduced-motion CSS.
- **Not verified on a real Android device:** visual likeness and tiny text at 64/128px; button touch/hitboxes; WebView/Chrome memory, frame rate, decode timing; long waves. A browser viewport smoke test is still required after branch preview publication.
- No newly published test build; no merge to `main`.
