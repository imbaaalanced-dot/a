# Denkmal TD v3.1.0-alpha.1

Integrated tester candidate based on v3.0.0-alpha.7.

## Tactical gameplay
- Every tower has a target priority: FIRST, STRONGEST, NEAREST or BOSS.
- Priority cycles near a tower with T or the contextual target button.
- Build pauses show the upcoming enemy composition.
- Mage slow primes Cannon for +25% impact/splash damage.
- Mage slow gives Rift Lance one additional chain jump.

## Alpha-7 retained
- Portrait-first layout and Safe Area handling.
- Touch joystick and mobile controls.
- Projectile sprites with procedural fallback.
- Existing FPS/enemy/FX tester telemetry.
- GitHub Pages delivery from dist/.

## Validation
- Regression tests cover targeting, wave preview, existing mobile behavior, asset references and combat synergies.
- Real Android sustained-play testing remains required before leaving alpha.
