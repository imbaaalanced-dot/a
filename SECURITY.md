# Security Policy

## Supported Versions

Denkmal TD2 ist ein fortlaufend entwickeltes Browser-Spiel mit Alpha-Builds.
Sicherheitskorrekturen werden grundsätzlich für den **aktuellen Stand auf
`main`** vorbereitet. Historische Test-/Preview-Builds werden nicht separat
gepflegt.

| Stand | Sicherheitskorrekturen |
| --- | --- |
| Aktueller `main`-Stand | ✅ |
| Historische Alpha- und Preview-Builds | ❌ |

## Reporting a Vulnerability

Bitte **keine öffentlichen Issues** für Sicherheitslücken öffnen.

- Bevorzugt: [Private Sicherheitsmeldung über GitHub](https://github.com/imbaaalanced-dot/a/security/advisories/new), sofern Private Vulnerability Reporting aktiviert ist.
- Alternativ: **imbaaalanced@gmail.com**

Bitte beschreibe die Auswirkung, betroffene Version und reproduzierbare Schritte,
ohne persönliche Daten oder Zugangsdaten mitzuschicken. Wir bemühen uns um eine
erste Rückmeldung innerhalb von sieben Tagen und stimmen eine mögliche
Veröffentlichung mit dir ab. Reporter können auf Wunsch genannt werden.
